Does Selfie Check actually open the camera?

A World ID 4.0 credential request for SelfieCheckLegacy, which is the only way to ask for a face check. @worldcoin/idkit-standalone — the widget the demo page used until today — cannot request it: its bundle contains no Selfie Check at all, only the four verification_level values device, document, secure_document, orb.

Nothing here touches the chain. No attestation is signed and no transaction is sent — this page exists to answer one question.
